## Что здесь


  Проект подключается к учебной базе данных ПРАЙМ и работает с персональным срезом данных - одной таблицей (transactions), одним сегментом (channel = web) и одним временным окном (май 2026). Ноутбук notebooks/hw1.ipynb считает общее число событий и долю успешных, суммарную выручку, самого активного участника, распределение выручки по дням недели и дате, а также скорость накопления суммы внутри месяца. Отдельно в ноутбуке разобрана обработка суммы с разными разделителями и поправка выручки на коэффициент дня недели.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

## Что здесь считается


- Количество и доля успешных событий — считается по столбцу `ok`: `True` — событие состоялось, `False` — не состоялось (например, отклонённая транзакция). Доля = число строк с `ok=True` делённое на общее число строк.
- Выручка (сумма `value`) — суммируется только по строкам с `ok=True`; неуспешные операции в выручку не включаются.
- Самый активный участник — участник с наибольшим числом строк `ok=True`; при равенстве выбирается по наименьшему `actor_id`.
- Распределение по дням недели — сумма `value` (по `ok=True`) группируется по дню недели, определённому из даты события (`day.weekday()`).
- Пиковые дни — три календарные даты с наибольшей суммой `value` (по `ok=True`).
- Поправка на день недели — выручка по каждому дню недели умножается на коэффициент из справочника `WEIGHTS` (для будних дней); для дней без явного коэффициента (выходные) применяется коэффициент `1.0` по умолчанию.
